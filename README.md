# Protein Pal

A dead-simple daily protein tracker for lifters. Log what you ate, see where you stand against your goal. That's it — no calories, no macros, no accounts.

Built for the [Devpost "Build With AI: Basics" hackathon](https://learn-ai-basics.devpost.com/) using the Devpost Learn Skill Pack (plan-first: `devpost/scope.md` → `prd.md` → `spec.md` → build).

## Run it

Just open `index.html` in any browser. No build step, no dependencies, no server.

## Features

- Log foods with protein grams (+ optional lactose/dairy flag ⚠️)
- Big daily total vs. adjustable goal (default 180g) with progress bar
- One-tap re-add from recent foods
- Per-day history with totals
- Everything persists in `localStorage` — works offline, no account
